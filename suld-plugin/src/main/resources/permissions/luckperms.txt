# LuckPerms groups SÜLD sets up once (permissions.auto-setup in config.yml; marker file plugins/SULD/.permissions-applied).
# One console command per line (without the slash). Lines starting with # are comments.
# Every player is in the "default" group, so its permissions are what an ordinary player can do beyond SÜLD's own
# commands (which are open to everyone). Staff groups inherit upwards: admin > mod > helper > default.

# ---- groups
lp creategroup helper
lp creategroup mod
lp creategroup admin
lp creategroup developer
lp creategroup streamer
lp creategroup sponsor
lp group helper setweight 10
lp group mod setweight 20
lp group admin setweight 30
lp group developer setweight 25
lp group streamer setweight 5
lp group sponsor setweight 5
lp group mod parent add helper
lp group admin parent add mod
lp group developer parent add mod
