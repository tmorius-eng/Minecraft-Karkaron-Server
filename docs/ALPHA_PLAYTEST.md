# Хаалттай альфа (15–20 тоглогч) — зохион байгуулах заавар

Зорилго: бодит хүмүүс Хархорумаас эхлээд эхний агуй **«Саарлын Агуй»** (`dungeon.khasar_den`, 3-р түвшнээс) хүртэл
хамтдаа тоглож, ойлгомжтой эсэх, тулаан сонирхолтой эсэх, лаг байгаа эсэхийг хэлж өгөх. Бот 500+ тест давсан ч хүний
нүдээр хараагүй зүйл энд л гарна.

## 1. Өмнө нь (хост)

* Серверийн бүтээл `main`-ийн сүүлийн commit, бүрэн restart (`/reload` биш). `docs/LOCAL_TEST.md` §7 «Цонхны
  шалгалт»-ыг өөрөө нэг удаа давна (GUI scale 2/3/4).
* Тоглогчдыг жагсаах (Discord / найзууд), Minecraft **Java 1.21.11**. `AUTH_MODE=online` бол Microsoft бүртгэлтэй;
  `AUTH_MODE=hybrid` бол offline клиент ч орно (нууц үг үүсгэнэ, `docs/AUTHENTICATION.md`). Bedrock дэмжихгүй.
* Тоглолтын өмнө: `/suldperf start` (гүйцэтгэлийн хэмжилт), тоглолтын дараа `/suldperf stop`.
* Мэдээллийн сан PostgreSQL дээр (analytics хадгалагдана).

## 2. Урилгын текст (хуулж явуулна)

> SÜLD — Монгол хэлтэй Minecraft MMORPG-ийн хаалттай туршилтад урьж байна. Огноо: … , цаг: … (2–3 цаг).
> Minecraft Java 1.21.11 хэрэгтэй. Сервер: `…`. Ороход resource pack асууна — **Yes** дарна уу.
> Тоглосны дараа 3 асуултад хариулна. Алдаа олбол `/report <текст>` гэж бичээрэй.

## 3. Тоглолтын дараалал (2–3 цаг)

| Хугацаа | Юу | Хост юуг ажиглах |
|---|---|---|
| 0–10 мин | Нэвтрэх, pack, анги сонгох (Академи / «Турших» дамми дээр) | pack-гүй орсон хүн байна уу, анги сонгох цэс нээгдсэн үү |
| 10–40 мин | Эхний даалгавар, хотоос гарах, эхний чоно | хаашаа явахаа мэдэж байна уу, combo (L-R-L / R-L-R) ажилласан уу |
| 40–90 мин | 3-р түвшин → баг (`/party`) → «Саарлын Агуй» | багаа олсон уу, агуйд орж чадсан уу, үхэл / `/trial` |
| 90–150 мин | Чөлөөт тоглолт, худалдаа, анги солих | лаг (TPS), алдаа, хэн юуг сонирхсон |

Хост тоглолтын үеэр: `/tps`, `/suldperf` тайлан; гацалт мэдэгдвэл цагийг нь тэмдэглэнэ.

## 4. Санал асуулга (тоглосны дараа, 1–5 оноо + нэг өгүүлбэр)

1. **Эхлээд ороход юу хийх нь ойлгомжтой байсан уу?** (1 = огт үгүй … 5 = маш ойлгомжтой) — хаана төөрсөн бэ?
2. **Ангиудын тулаан, combo сонирхолтой, ойлгомжтой байсан уу?** — аль анги, юу таалагдсан / таалагдаагүй?
3. **Сервер дээр гацалт, лаг мэдрэгдсэн үү?** (1 = их лагтай … 5 = огт үгүй) — хэзээ, юу хийж байхад?

4. **Ямар клиент, ямар данс ашигласан бэ?** (Microsoft данс / offline launcher) — hybrid нэвтрэлтийн шийдвэрийг энэ тоо
   батална (`ROADMAP.md` «Open questions»).

Нэмэлт: «Дахин тоглох уу?» (тийм / магадгүй / үгүй).

## 5. Дараа нь (хост)

* Funnel ба D1: `tools/analytics/funnel.py --url postgresql://suld:…@127.0.0.1:5432/suld --days 1`
  (нэвтрэлт → pack → анги → эхний тулаан → эхний бүлэг хаана хүмүүс унав).
* `/report` мөрүүд: аудит лог (`player.report`).
* Үр дүнг `docs/qa/ALPHA_<огноо>.md`-д: асуулгын дундаж, funnel хүснэгт, TPS/p95, олдсон алдаа (P0/P1/P2), хамгийн
  олон давтагдсан 3 гомдол. Түүнээс засварын дараалал гарна.
