# «Командын Өргөө» — SÜLD-ийн HD цонхны систем

Эзэмшигчийн зурсан загвар (`assets/art/source/gui_hub.png`, 1586 × 992) бол тоглоомын бүх цонхны хэв маяг: алт-хөх
хүрээ, хажуугийн тугууд, толгойн баннер, 8 таб, 8 командын карт, улаан «✕ Хаах». Энэ баримт тэр загварыг **яаж**
Minecraft-ын цонх болгосныг, шинэ хуудас хэрхэн нэмэхийг тайлбарлана.

## 1. Зарчим: chest цонх + title дотор зурсан HD давхаргууд

Minecraft-д серверээс нээдэг жинхэнэ цонх бол **chest (9 × 6)**. Түүний **гарчиг (title)** нь нүднүүдийн дараа,
хайчлагдахгүй зурагддаг тул гарчигт `suld:ui` фонтын зургийн тэмдэгт (glyph) тавьж, сөрөг зайгаар (`StyleFormat.shift`)
давхарлавал цонхны бүх талбайг — тоглогчийн цүнх хүртэл — HD зургаар бүрхэж чадна.

| Давхарга | Glyph | Юу |
|---|---|---|
| 1 | `HUB_FRAME` | хүрээ, тугууд, титэм, 8 табын хавтан (дүрс + бичиг), «✕ Хаах», цүнхийг нуух хар тууз, карт бүрийн доорх **нүх** |
| 2 | `PAGE_<НЭР>` | хуудасны гарчиг, дэд гарчиг, хэсгийн нэр + пилл, 8 карт (дүрс, нэр, тайлбар, сум) |
| 3 | `HUB_TAB_ON` | идэвхтэй табын цэнхэр гэрэл (18·i зайгаар байрлана) |
| 4 | `HUB_CARD_ON_R1..R4` | картын гэрэлт хүрээ (эзэмшсэн цол, асаалттай тохиргоо) — нэг зураг, мөр бүрт нэг provider |
| 5 | `HUB_BACK`, `HUB_PREV`, `HUB_NEXT` | хөлийн товчууд (зөвхөн хэрэгтэй үед) |
| 6 | динамик мөр | `suld:hd` фонтоор, дэд гарчгийн байранд төвлөрүүлсэн (жишээ: `Lv 12 · 340 зоос · Ард`) |

Бүх зураг **4×** (`hd_art.SCALE`): 1 GUI px = 4 texture px, тиймээс GUI scale 4 дээр зураг шиг тод.

Хэмжээ: канвас 212 × 244 GUI px, зүүн дээд өнцөг chest-ийн (−18, −22). Chest-ээс дээш **22 px-ээс өндөр юу ч зурж
болохгүй**: 1080p дэлгэц, GUI scale 4 дээр chest-ийн дээд ирмэг дэлгэцийн дээд захаас 24 px л доор байдаг.

## 2. Торлол (`gui/HubLayout.java`)

```
мөр 0   таб 0..7 (нүд 0–7), нүд 8 = чимэглэл / статистик
мөр 1–4 карт: зүүн = багана 0–3, баруун = багана 5–8, багана 4 = завсар
мөр 5   «Буцах» 45–46 · «✕ Хаах» 48–50 · өмнөх 52 · дараах 53
```

Карт бүрийн эхний нүдний доор хүрээнд **нүх** бий: дүрстэй хуудас түүнийг даавуугаар бүрхэнэ, **эд зүйлийн карт**
(дэлгүүр) нүхийг нээлттэй үлдээж тэр нүдэнд жинхэнэ `ItemStack` харагдана (`HubMenu.Card.item`).

`HubLayout.title(page, activeTab, cardMask, back, prev, next, dynamic)` гарчгийг угсарна; `HubLayoutTest` клиентийн
алхалтаар glyph бүр зөв x дээр буухыг шалгадаг.

### Текст хуудсууд (`ui/Pages.java`)

Чатаар урт текст гаргадаг байсан командууд одоо **dialog** нээнэ (толгой «SÜLD ◆ ГАРЧИГ», `suld:hd` мөрүүд, загварын
товчууд, «✕ Хаах»): `/help <хуудас>`, `/rules`, `/commands` (бүлэг бүр хуудас), `/discord /website /vote`
(`Pages.link`), `/clan info|top`, `/party info`, `/relic list|info`, `/loot`, `/classgear`, `/khuraldai status`,
`/duel status`, `/dungeon status`, `/item inspect|compare`. Консолд хуучин текст хэвээр. Богино баталгаа, алдааны
мөрүүд чатад л үлдэнэ.

## 4. Тооллого: tooltip, фонт, товч, нүдний гэрэл

- **Tooltip бүр** эрлийн номын хөх-алтан хүрээтэй: pack-ын *default* tooltip sprite (`minecraft:tooltip/background`,
  `frame`) = `suld:mongol`; `Menu.item` ба `ItemFactory` мөн `suld:mongol` style-ийг шууд тавьдаг.
- **`suld:hd` фонт** (`tools/pack/hd_font.py`): DejaVu Sans Bold-ын кирилл + латин дэд олонлог (75 KB, лиценз
  хажууд нь), TrueType provider, `minecraft:default` руу унадаг. Цэсний бүх текст (`Menu.title/line/kv`), dialog
  хуудас, динамик мөр үүгээр зурагдана.
- **Товчууд**: `minecraft:widget/button*` nine-slice-ийг хөх даавуу + алтан хүрээгээр солисон (dialog, Esc цэс).
- **Нүдний гэрэл**: `container/slot_highlight_back/front` — зөөлөн алтан гэрэл, цагаан дөрвөлжин биш.

## 5. Шинэ хуудас нэмэх

1. `tools/pack/hub_kit.py`: `Spec("нэр", "ГАРЧИГ", дэд гарчиг|None, "хэсэг", "пилл", [Card(icon, нэр, тайлбар) × 8])`.
   `icon` = kit-ийн дүрсний нэр (`compass chest scroll chart swords map arrows book`), PIL зураг, эсвэл `None`
   (нүхэнд жинхэнэ эд). **`LATER_PAGES`-ийн сүүлд нэм** — glyph-ийн кодууд зөвхөн нэмэгддэг, хэзээ ч шилждэггүй.
2. `python3 tools/pack/gen_ui.py --preview <хавтас>` → `hub_<нэр>.png`-ийг хар; хоёр удаа ажиллуулахад байт ижил.
3. Java: `HubMenu.open(p, new HubMenu.Spec(Glyphs.PAGE_НЭР, таб, динамикМөр, картууд, 9-р хавтан, буцах, өмнөх,
   дараах, cardMask), hubTabs())`.
4. `tools/loadtest/bots/hubbot.js`-д шалгалт нэм (гарчигт glyph байгаа эсэх, нүднүүд, чат гарахгүй байх).
